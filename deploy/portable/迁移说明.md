# 职业健康知识库迁移包说明

这个目录只包含新增的迁移工具，**不修改项目原有代码**。

## 一、在当前电脑导出迁移包

双击：

```text
导出迁移包.bat
```

脚本会生成：

```text
var/portable/oh-kb-migration-时间戳.zip
```

迁移包包含：

```text
source/                 项目源码（不含 .git / node_modules / .venv / var）
private/backend.env     当前后端配置
private/deploy.env      Docker Compose 配置
private/postgres.sql    数据库全量备份
private/requirements.lock.txt
data/storage            已上传文件
data/models             Embedding 模型权重
data/oh_chunks_v1.snapshot  Qdrant 向量快照
private/tunnel          Cloudflare Tunnel 配置和凭据
```

## 二、在另一台 Windows 电脑安装

1. 复制并解压 zip 到一个简单路径，例如：

```text
D:\oh-kb-migration\
```

2. 进入解压目录，双击：

```text
INSTALL.bat
```

安装脚本会自动：

```text
安装 Docker Desktop / Node / cloudflared / uv
创建 Python 3.12 虚拟环境
安装依赖
构建前端
恢复 PostgreSQL
恢复 Qdrant 快照
恢复上传文件和模型权重
恢复 Cloudflare Tunnel 配置
启动项目
```

默认安装到：

```text
解压目录\installed
```

## 三、验证

双击：

```text
VERIFY.bat
```

应看到：

```text
backend docs HTTP 200
frontend root HTTP 200
embedding health HTTP 200
documents=60
search smoke items>0
public MCP anonymous HTTP 401
5 个 watchdog 全部 OK
```

公网 MCP 匿名访问返回 `401` 是正确的，表示未授权访问被正常拦截。

## 四、重要提醒

### 1. 不要提交迁移包

迁移包里包含：

```text
数据库备份
真实 .env
API Key
Cloudflare Tunnel 凭据
标准文档
```

只能私下复制到目标电脑，不能提交到 Git。

### 2. 同一时间只能一台电脑运行公网隧道

如果新电脑复用原域名：

```text
https://kb.guanmingkun.ltd/mcp/
```

必须先停止旧电脑上的 tunnel，否则会冲突。

### 3. GPU 是可选的

安装脚本默认按 CPU 可运行配置。

如果新电脑有 NVIDIA GPU，安装完成并确认基础功能正常后，可运行源码里的：

```text
安装GPU向量化.bat
```

### 4. 如果目标电脑没有 winget

请先安装Microsoft Store 的 **App Installer**，然后重新运行 `INSTALL.bat`。

## 五、本方案对原项目的影响

本方案只新增：

```text
deploy/portable/
```

不修改以下原有文件：

```text
README.md
.gitignore
启动项目.bat
停止项目.bat
deploy/scripts/supervise.ps1
backend 源码
frontend 源码
```
